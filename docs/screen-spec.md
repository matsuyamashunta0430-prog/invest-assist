## 1. 共通仕様

### 1.1 レイアウト

すべての画面で `<SiteHeader>` と `<SiteFooter>` を共通とする（`src/app/layout.tsx`）。

| 領域    | 要素                                                            | 振る舞い                                                          |
| ------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| Header  | ロゴ（左）／ナビゲーション「シミュレーター・学ぶ・About」（右） | `sticky top-0 z-20`、`backdrop-blur` で半透明、375px 幅でも収まる |
| Content | `<main>` 直下                                                   | 各画面が `max-w-{3xl/5xl}` で中央寄せ                             |
| Footer  | © + 免責文                                                      | グレー背景、フォントサイズ `text-xs`                              |

### 1.2 デザイントークン

| カテゴリ         | 値                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| プライマリ色     | `#0F172A`（slate-900）                                                                            |
| 上昇色           | `#16A34A`（emerald-600）                                                                          |
| 下降色           | `#DC2626`（red-600）                                                                              |
| 背景色           | `#FFFFFF` / グレー系 `slate-50/100/200`                                                           |
| フォント         | Inter（英数）＋ Noto Sans JP（和文）／フォールバック `system-ui, "Hiragino Sans", "Yu Gothic UI"` |
| 角丸             | `rounded-xl` 基準（カードは `rounded-2xl`）                                                       |
| ブレークポイント | sm: 640 / md: 768 / lg: 1024 / xl: 1280                                                           |

### 1.3 アクセシビリティ要件

- WCAG 2.1 Level AA 準拠を目標
- すべての対話的要素は `Tab` キーで到達可能
- フォームの `<Label>` は `htmlFor` で対応する `<Input>` に紐づく
- スライダーは `role="slider"` + `aria-valuetext` + `aria-describedby` を持つ
- 色のみによる情報伝達を避け、テキストでも示す（例: 「+利益 ↑」）

### 1.4 メタデータ

| 画面       | `<title>` テンプレート                   | 説明                                 |
| ---------- | ---------------------------------------- | ------------------------------------ |
| トップ     | `invest-assist \| 投資初心者のための...` | サイト全体の代表説明                 |
| 個別ページ | `{ページ名} \| invest-assist`            | `metadata.title.template` 経由で自動 |

`metadataBase` は `NEXT_PUBLIC_APP_URL` 環境変数を参照。本番 Cloud Run では `https://invest-assist-upj37vyhzq-an.a.run.app` を設定済み。

## 3. 画面詳細

### S0. トップ `/`

**目的**: サイトの価値を 3 つの機能カードで伝え、ユーザーを Simulator へ誘導する。

**主要要素**:

- ヒーロー: 大見出し（2 行）＋ サブテキスト（1 段落）＋ CTA ボタン 2 つ
  - プライマリ「シミュレーターを試す」→ `/simulator`
  - セカンダリ「まず学ぶ」→ `/learn/videos`
- 機能カード × 3:
  1. NISA 積立シミュレーター（利用可能）
  2. 学べる動画とブログ（利用可能）
  3. 銘柄スクリーニング（Phase 2 で公開予定、グレーボタン）
- フッター免責文（サイト共通）

**レスポンシブ**:

- 375px: ヒーロー 1 列、カードは縦 3 段
- 640px+: ヒーロー幅 `max-w-3xl`、カード横 3 列
- 1280px: 上限 `max-w-5xl`

**状態**: なし（純粋な情報提示）

### S1. 積立シミュレーター `/simulator`

**目的**: 月額・利回り・期間からの将来資産シミュレーションを即時可視化し、ユーザーが意思決定できる状態にする。

**ルーティング**:

- Server Component (`page.tsx`) が `searchParams: Promise<Record<string, string | string[] | undefined>>` を `await` して `fromSearchParams` でパース
- パース結果を `<SimulatorClient initial={...}>` に渡す
- 不正な値はデフォルトに自動フォールバック（HTTP 500 を出さない）

**入力**:

| 項目         | 単位 | min | max         | step   | default |
| ------------ | ---- | --- | ----------- | ------ | ------- |
| 毎月の積立額 | 円   | 0   | 1,000,000   | 1,000  | 30,000  |
| 想定年利     | %    | 0   | 15          | 0.1    | 5       |
| 積立期間     | 年   | 1   | 50          | 1      | 20      |
| 初期投資額   | 円   | 0   | 100,000,000 | 10,000 | 0       |

各入力は `<Input>`（数値）＋ `<Slider>`（連動）の 2 入力を `useId` で紐付けたペア。`<Input>` は `inputMode="decimal"` でモバイルテンキー対応。フリッカ防止のため入力中はローカル draft state、blur/Enter で確定。

**出力**:

| 要素                  | 内容                                                              |
| --------------------- | ----------------------------------------------------------------- |
| サマリーカード × 4    | 最終評価額／総積立額／利益／利益率                                |
| Recharts 折れ線グラフ | 元本（グレー）／評価額（黒太線）／利益（緑）の 3 系列、年次間引き |
| マイルストーン        | 利益が +100万 / +500万 / +1000万 / +5000万に最初に達した「年月」  |
| 免責テキスト          | 「月次複利・期末払いモデル」「投資助言ではない」明示              |

**主要アクション**:

- スライダー／数値を変更すると即時再計算（`useMemo`）
- 「URL でシェア」ボタン:
  1. 現在の入力を `?initial=&monthly=&rate=&years=` 形式で `history.replaceState`
  2. `navigator.clipboard.writeText` で URL をコピー（フォールバックあり）
  3. 2 秒間ラベル変更してユーザーへ feedback。連打防止に `disabled + aria-busy`

**計算モデル**: 期末払い annuity ordinary（業界標準・楽天証券・SBI・金融庁準拠）。詳細は `src/lib/simulator/calculate.ts` の JSDoc。

**レスポンシブ**:

- 375px: 入力フォーム → 出力 の縦 1 列
- 1024px+: `grid-cols-[minmax(0,360px)_1fr]` の 2 列（左フォーム、右グラフ）

### S2. 学べる動画 `/learn/videos`

**目的**: 検証済みの YouTube 動画 10 本へ誘導し、初心者に学習順序を提示する。

**データソース**: `src/data/videos.ts`（10 件、カテゴリ別）

**主要要素**:

- ページ見出し + 「NISA 基礎 → インデックス基礎 → 失敗回避 の順を推奨」のリード文
- 動画カード（2 列、モバイルは 1 列）
  - カテゴリラベル / 動画タイトル（YouTube リンク） / チャンネル名 / 概要 / なぜ初心者向きか
- 外部リンクには `target="_blank" rel="noopener noreferrer"`

**カテゴリ**: `NISA基礎` / `インデックス基礎` / `失敗回避` / `英語補助`

---

### S3. 学べるブログ `/learn/blogs`

**目的**: 検証済みのブログ 10 本へ誘導。S2 と同構造。

**データソース**: `src/data/blogs.ts`（10 件、カテゴリ別）

**カテゴリ**: `公式・制度` / `インデックス基礎` / `失敗事例` / `長期実践記`

---

### S4. よくある失敗 `/learn/mistakes`

**目的**: 初心者がやりがちな失敗 5 つを明示し、回避策を学んでもらう。

**データ**: page.tsx 内に `MISTAKES` 配列（5 件、`as const`）

**5 件の内訳**:

1. 生活防衛資金がないまま全力投資
2. 暴落でパニック売り
3. 信託報酬の高い投信を選ぶ
4. 値動きの大きい商品で非課税枠を使い切る
5. 「次の銘柄」探しを繰り返す

各項目は番号 + 見出し + 1 段落の説明。

---

### S5. About / 免責事項 `/about`

**目的**: プロジェクト概要、免責事項、問い合わせ先を明示する。

**セクション**:

1. プロジェクト紹介（2 段落）
2. 計算モデルの説明（月次複利・期末払い・近似値である旨）
3. 免責事項（リスト 4 項目）
4. 問い合わせ（GitHub Issues、リポジトリ準備中の旨）
